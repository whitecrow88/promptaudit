# Privacy Policy - Wireframe Builder GPT

Last updated: 2025-10-18

## 1. Overview
Wireframe Builder GPT is an interactive AI assistant designed to help users create project wireframe templates and generate downloadable markdown files.  
This tool is built using OpenAI's Custom GPT platform and follows OpenAI's privacy and security policies.

## 2. Information Collected
- Wireframe Builder GPT does not collect, store, or share personal data outside your conversation session.  
- All interactions occur within OpenAI's secure infrastructure.  
- Temporary data such as app names, descriptions, and technical details are processed only to generate your markdown output.  
- No personal identifiers, emails, or credentials are required or stored.

## 3. Data Usage
The data you provide (for example, app details or project context) is used only to:
- Generate and export your wireframe blueprint markdown file.  
- Improve your in-session user experience.

No data is used for marketing, analytics, or tracking.

## 4. Third-Party APIs
Wireframe Builder GPT may optionally connect to a simple file generation API (hosted by the creator) for generating downloadable `.md` files.  
This API does not log, sell, or share user input.  
Only the generated file content is returned to the user.  
You can avoid API use by asking the GPT to output markdown inline.

## 5. Security
- All conversations and generated files are processed within OpenAI's encrypted environment.  
- If the optional API is used, HTTPS encryption secures all data transfers.

## 6. User Control
- You can delete or export your chat data directly via OpenAI's user settings.  
- To remove generated files, delete them from your local machine; no cloud storage is used.
